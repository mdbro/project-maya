Fidelity meter

A recorded answer is replayed through the engine token by token. At every position the next-token distribution under each rule is compared with the unmodified router's (bonus 0). Lower divergence means the rule changes the model less. For a neutral comparison, replay an answer written with the unmodified router (the preset "Unmodified router"): an answer written under a rule is slightly more likely under that same rule.
